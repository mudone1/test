Customers scan this code with their phone camera to open the ordering menu, build their own cart, and send the order straight to this till.
Demo note: this is a local, single-device sample. The QR code links to this app's own ordering page. For a phone camera to reach it, this file needs to be opened from a reachable URL (e.g. hosted, or opened on the same device that will "scan" it). Orders placed there are saved to this browser's local storage and appear under Customer orders.
